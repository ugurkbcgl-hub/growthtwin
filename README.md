# GrowthTwin

GrowthTwin is currently a project codename for an AI-assisted growth and content workflow for dental clinics in Türkiye.

This public repository starts with Phase 0: establishing a safe, affordable development workflow before building product features. See [PROJECT.md](PROJECT.md), [ROADMAP.md](ROADMAP.md), and the proposed [architecture](ARCHITECTURE.md).

The Phase 0 foundation currently consists of project/security/deployment/testing guidance, a modular architecture, an ADR process, and a Django application shell under `apps/web`. Django 5.2 LTS + PostgreSQL is accepted as the initial stack; local PostgreSQL installation and staging provider/cost remain open. No paid services have been provisioned. See [the ADR index](docs/adr/README.md) for recorded decisions.

No clinic/customer data or API credentials belong in this repository.
